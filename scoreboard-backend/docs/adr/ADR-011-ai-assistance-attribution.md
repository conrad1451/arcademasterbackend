# 11. Attribute AI-assisted code with `CHQ:` comments

- Status: Accepted
- Date: 2026-08-04 onward

## Context
Substantial portions of the code and configuration were generated or fixed with AI assistants (Claude Sonnet/Haiku, Gemini). The author wants this to be transparent.

## Decision
Mark AI-generated files and AI-suggested changes with `// CHQ: ...` comments naming the tool, and include a file-path header comment at the top of source files. Rejected alternatives and rationale are also noted inline (e.g. the `Math.max` alternative in `ScoreService`).

## Consequences
- Clear provenance for reviewers and for any academic or licensing disclosure.
- Comments can go stale; `CorsConfig` already had its "generated by" line removed when the file was rewritten, so attribution is not consistently maintained.
- Consider recording attribution in the README or commit trailers instead of scattering inline comments.
